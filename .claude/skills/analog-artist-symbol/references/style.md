# 风格与构图

## 先读电路

从 `symbol.inspect` 取得端口名、方向和端序。从 schematic 读实例 `model`、网名、连接关系和 pin pitch。器件类型、控制作用、输出极性以读回结果为准。

把下列信息写进 SVG：

- `<title>`：cell 名或功能名。
- `<desc>`：主信号路径、控制端作用点、内部节点、极性和重复结构。
- `<metadata>`：`terminal_order`、`ports`、`control`、`nodes`、`polarity`。
- `data-port`：每个外部端口一个唯一值。
- `data-side`：`left` / `right` / `top` / `bottom`。
- `data-direction`：`input` / `output` / `inputOutput`。

## 构图

信号通常从左向右；差分支路围绕共同水平轴镜像。电源在上，地在下；控制端靠近作用点。输入、输出、电源和控制按功能分组。

先安排主功能组和端口，再安排内部图、模块名、实例名和引线。复杂模块使用贴合内容的细矩形主体，引脚落在边界。按文字实际占用预留空间，长标签可旋转或移到端口外侧。

主信号、反馈、采样和时钟路径用连续实线。长距离辅助分发可用同名标签。控制关联可用虚线，虚线终点落在受控开关或功能组的作用点。交叉反馈在交叉处不画实心连接点。传播方向不明显时添加箭头。

## 配色与尺寸

| 项目 | 建议值 |
|---|---|
| 绿色图形 | `#287740` |
| 深绿连线 | `#425d4a` |
| 红色端口 | `#c53e32` |
| 红色端点方块 | `#df4638` |
| 普通文字 | 16 SVG 单位起 |
| 细线 | 1.5 至 2 SVG 单位 |
| 总线 | 2.5 至 3 SVG 单位 |
| 背景 | 白色或透明 |

保持端口名、功能字和位宽字号接近。关键正负号可局部放大。图面保留端口、必要节点、位宽、重复数、极性与短功能名。详细映射放入 `<desc>` / `<metadata>`。

## 检查

1. `python3 scripts/check_svg.py symbol.svg --json` 检查 viewBox、端口唯一性、`data-side`、`data-direction`、`metadata.terminal_order` 和 `<desc>`。
2. 用 `rsvg-convert` 渲染正常尺寸和父级常用缩放。检查端口标签是否贴近端点，文字是否重叠或裁切，填充是否遮住连线，节点是否为实心，空心圆圈是否保持空心。
3. 从图面追踪关键输出，确认能辨认输入来源、控制作用和极性。
4. 与 `examples/cmp_strongarm_symbol.svg` 对照端口组织、控制线终点和元数据写法。
