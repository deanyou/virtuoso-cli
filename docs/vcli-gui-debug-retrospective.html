IC25.1 API 语义知识库（沉淀）

✅ 已确认存在

API关键语义
hiCreateAppForm?name/?formTitle/?fields/?callback
hiCreateListBoxField?value 必须列表，永远返回列表
hiCreateToggleField?choices 每项 (symbol label)，?value 是 t/nil 列表
hiCreateComboField用 ?items 不是 ?choices
hiCreateCyclicFieldvalue 是单个字符串
hiCreateRadioField?callback 必须是 (list "...")
form->field->value唯一可靠的字段值读写方式
form->field->choices直接赋值动态更新选项
hiFormDone / hiFormCancel关闭表单（hiCloseForm 不存在）
lambda( (x) body)空格分隔，返回 funobj
hiCreatePulldownMenu + hiInsertBannerMenu菜单系统：pulldown/menuItem/sliderMenuItem(带子菜单)/separatorMenuItem，插入 CIW 横幅
hiCreateTabFieldTab 内字段必须 form->tab->page->field->value 访问，直接访问返回 nil
hiCreateReportField静态数据表，无动态更新 API
hiCreateSpinBox箭头 ~10px 难点击，优先 CIW 直接赋值 form->spinbox->value = n
hiCreateLayerCyclicField依赖 geGetEditRep() 非 nil，无打开 cellview 时崩溃，需 when(rep...) 守卫
hiCreatePointField / PointListField值为 (x y) 列表，渲染为只读文本
菜单 ?callback字符串直接 eval，函数未定义时报 undefined variable（回调确实触发了）

GUI 调试方法论（每操作 ≥2 种稳定方法）

操作方法一（推荐）方法二（备选）不推荐
点击xdotool mousemove --window + click（10ms）vcli action-x11 click-rel（1.3s，需服务端校验）OCR 千分比坐标
输入xdotool type --delay 10（120ms/20字）CIW 输入 + Return（425ms）vcli action-x11 type（乱码）
几何查询xwininfo -id（3ms）vcli list-windows-x11（940ms，需发现窗口时）截图测量
状态验证CIW 读 form->field->value（425ms，确定性）截图 + 人工确认（20ms，仅作证据）OCR 文本识别
坐标定位hiGetFieldInfo 反推 + 窗口 0 点偏移ImageMagick crop 像素级定位OCR 千分比（±40px 漂移）
文件对话框File name 输入 + Enter先处理模态对话框再操作主表单点击 Open 按钮（不稳定）
滚动vcli action-x11 scroll（全链路支持）xdotool click 4/5/6/7（local 模式）拖拽滚动条（精度差）
几何预检--direct 模式 xwininfo 预检（零尺寸/越界拒绝）batch 非 direct 共享 list-windows无预检直接发送（可能点到错误窗口）
