  延迟脱钩。Panic message 也分清"推广逻辑过早"（真回归）vs"调度延迟越过 grace"

## Security Audit 红灯（pre-existing，独立于 PR #29）

**根因**：`cargo audit` 命中 `rsa 0.10.0-rc.18`（经 `ssh-key` → `russh`，`native-ssh` feature 专用）：
- **RUSTSEC-2023-0071** Marvin Attack：计时侧信道潜在密钥恢复 — Solution: **No fixed upgrade is available!**
- RUSTSEC-2024-0436 unmaintained
- RUSTSEC-2026-0002 / RUSTSEC-2026-0253（同 crate 后续 advisory）

**攻击面评估**：
- `rsa` 仅经 `russh`/`ssh-key` 进入，而 `russh` 是 `optional`，只在 `--features native-ssh` 下编译
  （`Cargo.toml:34 native-ssh = ["russh", "russh-sftp"]`）。
- **默认构建（无 native-ssh）不链接 rsa**，Marvin 攻击面在默认二进制中不存在。
- Marvin 需对 RSA 私钥解密做大量选择密文 oracle 查询；SSH 中 rsa 多用于签名/验签（公钥运算），
  实际可利用性低，但 advisory 仍按 crate 版本触发。

  而 `build_xdotool_actions`（`x11.rs:1154-1165`）生成 `windowraise --sync --window <id>` → 双重语法错误。

- **`click`/`mousedown`/`mouseup` 无 `--button` 选项**，button 是**位置参数** `click [options] button`。
  而 `x11.rs:1210-1220` / `1242-1244` / `1262-1266` 硬编码 `"--button"` → 报告 #7/#8 同类错误。
- **`ctrl-s` 连字符 chord**：man page 明确「Multiple keys are separated by '+'」，全版本一致。
